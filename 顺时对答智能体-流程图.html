STEP 02 · 对答

一次问齐，最多 2 轮

能推断就推断，绝不逐项追问。首次只问两句：① 省 / 市 / 区县　② 需要照顾的情况（年龄、肩颈、出汗、慢病孕期等）。 缺的用保守默认值，生成后说明用了哪些默认值；位置沿用 jx_loc 记忆。
date　默认今天 location　首次必填，到县级 health_notes　自述，非诊断 constraints　慢病 / 孕期 → 保守模式 intensity　RPE 9–11 中低强度 skin　按天气自动匹配
↳生成前一行确认：已收集槽位 + 将要调用的能力；用户回「生成」即执行。
3
STEP 03 · 决策

安全闸门过得了吗？

前置且优先级最高：先声明「这不是诊断」→ 判红旗 → 建议就医 → 只给保守动作 → 只问会改变安全结论的问题。
红旗　胸痛胸闷 / 晕厥 / 急性损伤 / 高热 求诊断 · 方药 · 吉凶　明确拒答 慢病 / 孕期 / 术后　降一档 + 先问医生 正常　放行
✕拒答分支：说明边界 → 给保守回应 → 回到入口；不生成运动建议。其余情况照常生成，但删除相关推断、不含任何方药。
放行后装配上下文

STEP 05 · 分叉

同一份 cal，两条产物

长页给全量信息，卡片给可发布的一屏重点；文案同源，不会打架。

  • 四层依据 + 风险提醒表
