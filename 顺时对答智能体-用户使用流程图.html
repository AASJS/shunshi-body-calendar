1
STEP 01 · 开口

像发消息一样说一句

不用记命令、不用选参数。智能体会自己听懂你要什么；两份成品（长页 + 9:16 卡）是默认，只要一种也行。
你 说 · 任选一句
生成今天的身体日历，再出张卡
42 岁，久坐腰膝酸软，睡眠不佳，怕冷，在四川成都锦江区
做张 9:16 的卡 ／ 只要 Markdown ／ 明天呢
生成　长页 + 卡（默认） 只要长页　给我 Markdown 只要卡　做张 9:16 重算　按我这情况再来一份 想改　换第 7 套 / 强度再降一点 想懂　这条建议依据是什么
!若你问「是不是颈椎病 / 给个化痰方 / 今天宜不宜出门」，会被温和拦下并说明边界，其余养生建议照常给（详见页脚）。
2
STEP 02 · 对答

它最多问你两句

它 答 · 首次只问这一句
好的，先确认三件事：① 你的年龄，② 身体状况 —— 有没有需要照顾的情况（性别、肩颈、出汗、慢病孕期，简单说就行），③ 你在哪个省 / 市 / 区县？不说也行 —— 我按「普通健康成年人 · 中低强度保守版」生成，位置沿用上次记忆。
全答　省市县 + 年龄 + 自述，一步到位 简答　只给「陕西汉中西乡县」 跳过　回「用默认值」或「生成」 同名县　它会列候选让你点一下
↳能推断就推断，绝不逐项追问；最多 2 轮，缺的用保守默认值，生成后会告诉你用了哪些。身体情况只作保守调整，不当诊断写进去。

4
STEP 04 · 收成品

一次拿到三样

两份成品 + 一段对话文字。留意与免责不上卡面，改由对话告知，发稿时补进正文即可。
成品 A · 长页中医身体日历
  • 10 字段全量：主题 / 宜 / 不宜 / 作息 / 饮食 / 运动 / 情志 / 五问 / 风险 / 依据
  • 今日档案 + 个人化说明 + 四层依据
  • 作息带时间点，运动带热身—主项—收操—停止信号
→ .md / .html / 长图 .png；可打印存 PDF、粘进排版助手
成品 B · 卡片国风养生日历卡 9:16
  • 1080×1920，无配图、重要信息大字
  • 宜忌每条压到一行，版面舒展不挤
  • 卡面只留「依据」（左下，避开右下印章）
→ .html + .png；可直接发号；「复制文案」里带留意与免责全文
＋对话文字告知：留意（红旗症状 / 防风防滑 / 慢病孕期先问医生 / 就医门槛）与 落款说明（免责边界 + 日期 · 节气 · 区县 · 模板名 · 天气取值时刻）。
5
STEP 05 · 修订

想改，再补一句就行

你 说 · 任选一句
换到成都双流区 ／ 强度再降一档 ／ 换第 7 套
只要 Markdown ／ 为什么今天不能练到大汗 ／ 明天呢
换城市　天气与建议一起变 换皮肤　只换配色，长页不动 降强度　建议更保守一档 解释依据　直接答原因，不重做 改日期　明天按排期预览，天气留空
↺修订回环：只重算改动涉及的部分，不用重新回答前面那些问题，也不会从头再来。满意就进下一步。
