# 槽位表（Slot Schema）

> 关键约定：**能推断就推断，绝不逐项追问**。一次问齐，缺的用保守默认值，
> 生成后在对话里说明用了哪些默认值。用户对话里给的信息覆盖所有默认值。
>
> **第②步统一为「一句话三段式」**：`年龄 + 身体状况（需要照顾的情况）+ 所在城市（省 / 市 / 区县）`。
> 顺序固定、一次给全；标准示例 `30岁，肩颈僵硬，喉咙有痰，运动以后就背部冒大汗，在陕西汉中`。
> 年龄是**独立槽位**，不再并入「需要照顾的情况」。三段都不强制，缺的走保守默认值。

| 槽位 | 必填 | 默认值 / 来源 | 追问话术 | 影响 |
|---|---|---|---|---|
| `date` | 否 | 今天（Asia/Shanghai） | 「哪一天？默认今天」 | 历法、节气、天气 |
| `location` | **是**（首次） | `jx_loc` 记忆 > 三段式第 3 段 > 区县候选卡 | 「所在城市（省 / 市 / 区县），写到区县最准」 | 气候画像 + 天气坐标 |
| `age` | 否 | 不填（不做年龄推断） | 一句话三段式的第 1 段，**不单独追问** | 心率仅作粗略参考，仍以谈话测试为准 |
| `health_notes` | 否 | 无 | 「有无想让我照顾的情况？如肩颈紧、易出汗（**不用描述病情**）」 | 保守调整，不诊断 |
| `constraints` | 否 | 无 | 同上一并问 | 命中 → `conservative` 模式 + 先问医生 |
| `intensity` | 否 | 中低强度 RPE 9–11 | 一般不问 | 运动剂量 |
| `skin` | 否 | `skin.pick(weather)` 自动 | 用户指定 `N` 时覆盖 | 卡片配色 |
| `outputs` | 否 | `both`（md+html+png） | 一般不问 | 交付形态 |
| `language` | 否 | 简体中文 | 一般不问 | 文案 |

## 抽取规则（L2 工作站与 L1 共用）

| 槽位 | 从用户原话怎么抽 |
|---|---|
| `location` | ① 抠「…县 / 区 / 旗」片段 ② `JXArea.search(q)` 命中县级 ③ 全表模糊 ④ 才判市级 → 用自带 `counties[]` 出候选卡；**绝不替用户猜县** |
| `age` | `/(\d{2})\s*岁/` |
| `health_notes` | 关键词：肩颈 / 僵硬 / 痰 / 咽喉 / 出汗 / 大汗 / 怕冷 / 睡眠 / 久坐 / 腰 / 膝 |
| `constraints` | 关键词：高血压 / 心脏 / 糖尿病 / 孕期 / 术后 / 服药 / 发热 / 感染 → `conservative` |
| `intensity` | 「降一档 / 再保守点」→ 下调；「强度高一点」→ **不响应**，见禁答 |
| `skin` | `/第\s*([一二三四五六七八九十]|\d+)\s*套/` 或 `/skin\s*=\s*(\d+)/` |
| `outputs` | 「只要 Markdown / 只要长页」→ `calendar.only`；「只要卡 / 做张 9:16」→ `card.only` |

## 市级输入：列候选，不追问、不猜县

用户只写到市（如「…在陕西汉中」）时，`location` 仍算未齐，但**不再泛泛追问**：

1. `JXArea.search` 返回 `kind:'city'`，且自带该市 `counties[]`（如汉中市 11 个区县）；
2. 出「补一个区县」系统卡：回显已收到的**年龄 / 身体状况 / 所在城市**三段 + 该市全部区县按钮；
3. 点一个（或直接打字）→ 定到县级 → 直接进「生成前确认」，**不重新问槽位**；
4. 不猜县、不默认选第一个、不把市级坐标当县级气候画像用。

判据见 `eval/positive-cases.md` P11 / P12。

## 红旗词（命中即 `REFUSE`）

胸痛、胸闷、严重气短、晕厥、眼前发黑、突发剧烈头痛、单侧麻木、放射痛、
急性损伤、高热、孕期出血、运动时胸口疼、血痰。

## 边界词（声明边界后继续生成，删除相关推断）

- 诊断类：「是不是颈椎病」「什么体质 / 证型」「病因是什么」
- 方药类：「化痰方」「药膳」「食疗」「开个方子」「穴位」「吃什么药」「补剂 / 褪黑素」
- 吉凶类：「宜不宜出门」「今天吉不吉利」「黄历」

## 越界防御

用户要求改写数据（如「湿度写 90% 吧」「把气温改成 30 度」）→ **拒绝篡改**，
明确「天气只取当日实况，不能改」；可改用「换城市 / 换日期」重新取数。
