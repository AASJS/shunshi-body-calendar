# 卡面 12 字段 · 长度上限

> 模板：`/workspace/国风养生日历卡-西乡县.html`、`国风养生日历卡.html`。
> **9:16 = 1080×1920，零 SVG / 零 img / 零 emoji / 零配图区，大字版，卡面只留「依据」。**
> 留意与落款说明**不上卡面**，生成后由对话文字告知（Gotcha G8）。

## 字段映射表

| # | 卡面位置 | 从 `cal` 取 | 长度上限 | 裁剪方式 |
|---|---|---|---|---|
| 1 | 刊头套号 / 名称 | `skin` 元数据 | 第 N 套 · 四字名 | — |
| 2 | 日期 / 农历 | `dateText` `lunarText` | 大号日数字 + 3 行 | 月份 / 星期 / 农历各一行 |
| 3 | 节气进度 | `termLine` + `place` | 一行 + 地点标签 | 「立冬 · 第 2 天 · 距小雪 14 天」 |
| 4 | 天时四格 | `weather` | 4 格，每格 1 值 | 天气 / 气温 / 湿度 / 阵风 |
| 5 | 天气实况行 | `wxLine` | 一行小字 | 超长截到「实况 · 区间 · 无雨 · 日出日落 · 取值时刻」 |
| 6 | 今日主题 | `theme.title` | ≤ 14 字 | 取主标题，去掉副题 |
| 7 | 宜 3 条 | `yi[0..2]` | **每条一行 ≤ 20 字** | 取句首动作短语，不做改写 |
| 8 | 忌 3 条 | `bu[0..2]` | **每条一行 ≤ 20 字** | 同上 |
| 9 | 四时调摄 4 行 | `sleep[0]` `food[0]` `move[0]` `mind[0]` | 每行 ≤ 26 字 | 取每组第一条的句首 |
| 10 | 今日一问 | 内观五问之一 | ≤ 30 字 | 取与 `health_notes` 最相关的一问 |
| 11 | 一句话 | `oneLine` 或主题收束 | 2 行 | 手动折行，不挤印章 |
| 12 | **依据** | `basis[]` 压成一行 | 左下角固定条，小字 | 四层各取关键词，右界 ≤ 844px |

## 版式硬约束（实测值）

| 项 | 值 |
|---|---|
| 画布 | 1080 × 1920（0.5625 = 9/16） |
| 内框 | inset 26px；左右 padding 76px |
| 依据区 | `position:absolute` 左下角固定条；右界 844px < 印章左界 892px |
| 印章 | 右下，四字单列，字号 26.5px 不参与缩放 |
| 一句话底 → 依据顶间隙 | 稳定 **41px**（十套一致） |
| 关键组字号 | 累计约 1.38 倍；依据保持原小字、行距 1.5 |

> 宜忌每条必须压到一行。多一行就会把「依据」挤到印章上（实测间隙从 41px 掉到 2px）。
> 这正是必须用**单一数据源 `cal` + 长度裁剪**的原因：人工誊写极易多一行。
