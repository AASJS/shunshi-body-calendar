# 长页模板 · 10 字段

> 可直接套用版式：`/workspace/中医身体日历-2026-11-08-立冬-陕西汉中西乡县.md` / `.html`。
> 本文件只列**字段契约与写作约束**；所有文字必须从 `cal.build()` 产出的 `cal` 映射，不得另写一套。

---

## 结构（顺序固定）

| # | 段 | 从 `cal` 取什么 | 约束 |
|---|---|---|---|
| 0 | 标题 + 引题 | `theme.title` / `theme.desc` | 引题点明节气 + 当地天气 + 一条重点；不写诊断结论 |
| 0b | **今日档案**表 | `dateText` `lunarText` `termLine` `place` `wxLine` `chips` | 天气数字只取实况，标注取值时刻；断网写「天气缺席」 |
| 0c | **个人化说明**（有自述时必有） | `profile` 自述 → 保守调整表 | 固定写「据此做保守调整，非诊断」；不判断体质 / 证型 / 病因 |
| 1 | 今日主题 | `theme` + `basis[内经]` | 经典引文标「作养生取向，非诊疗」 |
| 2 | 今日宜 | `yi[]` | **行为与生理提醒，不是吉凶**；每条可执行 |
| 3 | 今日不宜 | `bu[]` | 同上；不写「忌出门 / 忌动土」类黄历语 |
| 4 | 作息 | `sleep[]` | 给时间段；泡脚须带 ≤40 ℃、10–15 分钟、不出汗及禁忌 |
| 5 | 饮食 | `food[]` | 只给食物类别与结构；**无药膳 / 食疗方 / 药材 / 化痰方** |
| 6 | 运动 | `move[]` | RPE 9–11、谈话测试、20–30 分钟、热身、汗后管理；心率仅粗略参考 |
| 7 | 情志 | `mind[]` | 呼吸放松、允许留白；持续低落 2 周以上建议专业评估 |
| 8 | 内观五问 | 由 `health_notes` 派生 5 个**只记录事实**的问题 | 不自我诊断、不对号入座、不据此调药 |
| 9 | 风险提醒 | `risk[]` + 固定红旗表 | 红旗、先问医生、症状持续就医门槛、边界声明 |
| 10 | 依据（四层） | `basis[]` | 经典 / 现代规范 / 气象 / 历法区划，四层齐；末注「均非医疗建议」 |

## 写作约束（对应 Gotchas）

| # | 约束 |
|---|---|
| G1 | 宜忌标题固定带「（行为提醒，非吉凶）」 |
| G2 | 饮食段显式写「不含药膳、食疗方、药材或任何化痰偏方」 |
| G3 | 不出现任何补剂、褪黑素、保健品名 |
| G5 | 天气数字后标来源与取值时刻；断网不编 |
| G7 | 个人化说明的「不做什么」列必须写「不诊断 / 不判断体质证型 / 不开方」 |
| G8 | 长页可写留意与免责（卡面才不写） |

## 输出格式

| 格式 | 说明 |
|---|---|
| `.md` | 永远能出；Markdown 表格 + 引用块，便于发稿与二次编辑 |
| `.html` | 宣纸风长页版式，可直接打印 / 存 PDF |
| `.png` | 2x 高清长图（示例 2160×9076），用无头浏览器截图 |

> 长页与卡片共用同一 `cal`。若卡面某条宜忌压到一行，长页仍保留完整句子 —— 差异只允许是**长度裁剪**，不允许改写措辞。
