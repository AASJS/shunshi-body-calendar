# 对话模板（四套：追问 / 确认 / 拒答 / 修订）

> 全部用简体中文、平和语气；用「建议 / 可 / 避免 / 如有不适」，不用「必须 / 一定」。

---

## 1. 首次追问（一句话三段式，最多 2 轮）

> 一句话给我三样就行：
> **年龄 + 身体状况（需要照顾的情况）+ 所在城市（省 / 市 / 区县）**
> 例：42岁，久坐腰膝酸软，睡眠不佳，怕冷，在四川成都
>
> 写到区县最准；只写到市，我把该市的区县列出来给你点一下。
> 不说也行 —— 我按「普通健康成年人 · 中低强度保守版」生成，位置沿用上次记忆。

若用户只给了位置、没给身体情况 → 不再追问，直接进入确认，注明「身体状况：未填，按通用保守版」。

### 1b. 只写到市级：补区县卡（不追问）

> 收到了。这句话里的「陕西省汉中市」只到市级 —— 养生建议要按区县气候画像来调，
> 补一个区县就齐了（下面点一下即可，也可以直接打字）。
> 三段已收到：**年龄** 30岁 · **身体状况** 久坐腰膝酸软 / 睡眠不佳 / 怕冷 ·
> **所在城市** 陕西省汉中市（待补区县）。

系统卡字段：`年龄 / 身体状况 / 所在城市 / 候选区县（共 N 个）`；按钮为该市全部区县 + 「用默认值」。
点选后回：`已定位到 陕西省汉中市西乡县。三段都齐了，下面是生成前确认。`

## 2. 生成前确认（一句话）

> 已收集（三段）：**年龄** `42岁` · **身体状况** `久坐腰膝酸软 / 睡眠不佳 / 怕冷` ·
> **所在城市** `陕西省汉中市西乡县`；日期 `2026-11-08` · 强度 `中低（不出大汗）` · 皮肤 `自动匹配`。
> 接下来查实时天气 + 离线历法，跑三层规则引擎，出「长页 + 9:16 卡」。要改现在说，或直接回「生成」。

若用了默认值，追加一行：
> 本次默认：日期取今天、强度中低、皮肤按天气自动、两份产物一起给。

若命中 `conservative`（慢病 / 孕期 / 术后 / 服药），追加一行：
> 你提到的情况属于需要更谨慎的范围，本版强度再降一档，并加上「先咨询医生」；这不构成任何医学判断。

## 3. 拒答 / 边界回应

### 3.1 红旗症状（**不生成运动建议**）

> 先说明：这不是诊断。你提到的 **胸痛 / 胸闷 / 头晕 / 严重气短** 属于需要及时评估的信号，
> 建议先停止活动、尽快就医，别靠养生日历来判断。
> 这部分我不能给运动建议。等症状经医生评估后再恢复规律活动，届时我可以帮你排一份很保守的日常作息。

### 3.2 求诊断 / 证型

> 这部分我不能给：本智能体只做**日常养生教育**，不诊断、不判断体质或证型、不开方药、不判吉凶、不承诺疗效。
> 你提到的情况若持续或加重，建议就医评估。其余的作息 / 饮食 / 中低强度活动建议，我可以照常生成（会更保守一档）。

### 3.3 求方药 / 药膳 / 化痰方 / 穴位 / 补剂

> 方药、药膳、食疗方、穴位处方和补剂都不在我的范围内，我不能给。
> 能给的只有通用舒适护理：温水、适宜室内湿度、挡风、减少刺激、别过度用嗓。
> 喉咙的不适若持续超过 2 周，或伴发热、气短、明显咽痛，请就医评估。

### 3.4 求吉凶

> 「宜 / 不宜」在这里是**行为与生理提醒**，不是黄历吉凶，也不预测顺不顺。
> 我可以把它翻译成今天具体怎么穿、什么时候出门、运动做到什么程度 —— 要我按这个生成吗？

### 3.5 要求篡改数据

> 天气和历法只取当日实况与离线算法，不能按指定数字改，那样会变成编数据。
> 想换条件可以说「换到成都双流区」或「看明天」，我重新取数。

## 5. 解释意图（`explain`）

> 「今天不出大汗」这条来自三层叠加：
> ① 节气基调：立冬，《四气调神大论》「去寒就温，无泄皮肤」，养生取向是护阳不泄；
> ② 区县气候画像：陕西属北方干冷、温差大、多风，汗后受凉风险更突出；
> ③ 当日天气：湿度 43 %、阵风 22 km/h、体感低于气温，触发「空气偏干 + 风力偏大」两条规则；
> ④ 冬三月「无泄皮肤」总纲 + 怕冷自述 → 避免练到大汗，汗后立即擦干避风。
> 现代依据是 WHO 2020 与 ACSM 强度分级（RPE 9–11、谈话测试），用于剂量与安全阈值，不是疗效证据。
> 这不是诊断，也不预测吉凶。
