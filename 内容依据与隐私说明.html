一、健康内容的四类来源

1. 经典总纲 ——《黄帝内经 · 素问 · 四气调神大论》

四时节律与作息基调由此而来：春三月「夜卧早起」，夏三月「夜卧早起，无厌于日」，秋三月「早卧早起，与鸡俱兴」，冬三月「早卧晚起，必待日光」。生成产物中的作息主线、宜忌方向与「收」与「泄」的节气总述，均取自该篇原文精神，只做白话转述，不做经文发挥。

2. 历法框架 —— 二十四节气与农历（离线内置）

节气日期与农历干支由内置历法表（TERM_DATA）离线推算，不依赖网络。产物中「节气已过 N 天、距下一节气 N 天」即由此计算，用于把经典总纲落到「今天是哪一节气、处在哪一段」。

3. 现代剂量与安全阈值 —— 大众运动健康通识指引

运动强度采用 RPE 自感用力等级（本库默认 9–11，即「能正常说话、微微出汗」），配合热身加倍、微汗即止、运动后不立即洗浴等大众通识边界；泡脚限水温不高于 40℃、10–15 分钟。剂量数字取保守下限，宁低勿高。

4. 当日条件 —— 区县气候画像 + 实时天气

全国 2995 个区县离线内置气候常识画像（干冷 / 湿冷 / 湿热 / 高原等），定位精确到县；可选联网时经 Open-Meteo 免密钥接口取当日天气作增量提示。天气接口不携带任何个人数据，也不需要账号。

经典提供思想框架，现代指南提供剂量与安全阈值，气象与历法提供当日条件；三者合成当日的宜、忌、作息与运动边界。四者均不构成医疗建议。

二、审校方式：固定规则，不是自由发挥

  • 规则库人工沉淀：所有提示条目来自人工整理的固定规则库（按节气 × 气候画像 × 天气增量组合），生成时按规则拼装，不存在每次随机改写；同一天同一地点，生成结果可复现。
  • 安全边界内置：全程不诊断、不开方药 / 药膳 / 穴位、不判吉凶、不承诺疗效；任何情形下红旗症状一律提示「立即停止并就医」。
  • 运动默认保守：默认中低强度，并对高血压、糖尿病、孕期、术后恢复等情形给出「先咨询医生」的保守提示。
  • 可回归验证：生成结果、区县解析、医疗安全边界均有自动化测试（tests/ 目录），每次提交都会重复验证，防止规则被误改。
  • 使用建议：产物仅供健康生活参考。有慢性病、孕期、术后恢复或症状持续加重的，请先咨询专业医生，就医请遵医嘱。

三、本机记忆（localStorage）保存什么

工具是纯离线单文件 HTML，没有账号体系、没有服务器存储。你的三件事（年龄、身体状况、所在区县）只保存在浏览器本机的 localStorage 里，用于下次打开时自动带出、不必重报。具体键如下：

键名保存内容写入页面
jx_loc最近一次确认的省 / 市 / 区县定位顺时对答智能体
shunshi_profile年龄 + 身体状况（需要照顾的情况）+ 个性化约束顺时对答智能体
shunshi_skin上次选择的国风皮肤序号（1–10）顺时对答智能体
shunshi_last最近一次生成的日历快照（打开页面自动恢复）顺时对答智能体
jx_cal_loc县级联动内核的定位记忆身体日历 · 县级联动 / 一源多出
隐私承诺：以上数据只存本机浏览器，不上传、不同步、无统计埋点、无 Cookie。除可选的天气查询（Open-Meteo，请求中不含任何个人数据）外，页面不发起任何网络请求。清除浏览器数据即彻底删除，我们无法帮你恢复，也不会留副本。

方式 2 · 浏览器设置手动清除

浏览器设置 → 隐私与安全 → 清除浏览数据 → 勾选「Cookie 及其他站点数据」。本地双击打开的页面（file://）可在地址栏站点权限里单独清除，或直接清除全部站点数据。

方式 3 · 开发者控制台

在工具页面按 F12 打开控制台，输入 localStorage.clear() 并回车，刷新页面即恢复空白状态。
