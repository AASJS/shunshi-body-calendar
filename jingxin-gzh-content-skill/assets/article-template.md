# Article Template · 六段反共识骨架

Use this template for `full` and `outline` outputs. Keep calm, grounded, non-panic tone.

```markdown
# [标题：真实价值钩子，不恐吓]

## 1. 钩子 Hook
[一个具体、不夸张的生活场景，或一句反直觉的提问。把读者拉进自己的处境，
例如"你有没有发现，越是想快点变好，越容易原地打转？"]
（避免："再不X就晚了""同龄人已经……"）

## 2. 反共识 Counter-consensus
[点出一条被大众默认为真的假设，给出你的不同看法。
例：大众认为"努力就要看到即时回报"，我认为"看不见回报的阶段恰恰是扎根期"。
必须可辩护，不是抬杠。]

## 3. 支撑 Evidence
- 模型：[可复用的思维模型/框架，如控制二分法、复利思维]
- 案例：[真实或匿名化的具体故事]
- 数据：[可查证的研究/统计，无出处则标"示意"]
- 金句：[一句话可引用的观点]

## 4. 破局 Reframe
[把"问题"重新定义为"选择"。给读者一个可迁移的思维视角，例如
把"我落后了"重构为"我在按自己的节奏积累"。给希望，不给鸡汤。]

## 5. 行动 Action
- [小步、低成本、今天就能开始的 1-3 条建议]
- [拒绝完美主义启动，强调"先做一点比想清楚再做强"]

## 6. 收束 Close
[一句金句，或回到长期主义的余味。不催促、不恐吓。]
```

## Tone

- 平和、笃定、不油腻；像一个有阅历的朋友在说话。
- 用"可以试试 / 值得考虑 / 也许"，不用"必须 / 一定要 / 赶紧"。
- 给确定性，不给恐慌；给希望，不给鸡汤。

## Personalization Slots

If the user gives context, adapt:

- 职场困境：锚定"可控 vs 不可控"，给注意力重分配的小步。
- 育儿/家庭：去比较、去完美主义，强调长期陪伴节奏。
- 自我成长焦虑：用"复利"替代"速成"。
- 中年转型：强调"重新开始不晚"的确定性证据，不画大饼。
