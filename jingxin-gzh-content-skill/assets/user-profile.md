# 账号画像

> 填写后，内容生成会自动按这些信息产出。对话中提供的信息覆盖这里。

---

## 基本信息

account: 静心（公众号）
positioning: 反共识认知 · 长期主义 · 反焦虑表达
audience: 30-50 岁，面临内心困境与思维破局的人
platform: 公众号（为主）
tone: 平和、笃定、不油腻

## 内容方向

default_topic: 反共识认知 / 长期主义 / 反焦虑
# 可填具体方向，例如：
# - 职场里的"慢就是快"
# - 为什么越努力越焦虑
# - 重新定义"落后"

## 素材偏好

material_focus: 金句 / 模型 / 案例 / 数据（四类都要触达）
# 每篇至少用两类，full 产出建议四类都覆盖

## 产出格式

output_format: full
# full     = 完整公众号长文（六段骨架，默认）
# outline  = 选题 + 六段大纲 + 素材建议
# titles   = 标题/开头钩子库（含 AB 测试分组）
# cards    = 金句/模型/案例/数据 素材卡

## 输出目录（可选）

output_dir: ~
# 留空则只在对话显示；填路径可写入文件
# 例如 ./output/ 或 D:/Obsidian/公众号素材/
