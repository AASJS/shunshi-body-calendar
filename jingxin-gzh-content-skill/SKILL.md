# 静心·公众号内容生成器

**做什么**：基于「反共识认知 + 长期主义 + 反焦虑表达」的方法论，生成公众号内容——
选题与大纲、全文草稿、标题库、素材卡片（金句/模型/案例/数据）四类产出。

**不做什么**：不制造焦虑、不贩卖身份恐慌、不承诺速效、不做标题党、不编造数据。
详见 `references/style-boundary.md`。

---

## 核心原则

1. **反共识，但必须有据**——推翻大众默认假设可以，但要在逻辑或素材上站得住，不能为反而反。
2. **长期主义视角**——所有建议指向"可持续的小步"，而非"立刻翻盘"的爽文叙事。
3. **反焦虑表达**——把读者从"我是不是落后了"里拉出来，给确定性，不给恐慌。
4. **四类素材驱动**——每篇至少用上「金句 / 模型 / 案例 / 数据」中两类，避免空泛说教。
5. **不投流，靠内容本身**——标题要真有价值钩子，不靠恐吓和噱头骗点击。

---

## 写作框架（六段反共识骨架）

> 这是本 Skill 的默认文章结构，所有 full 产出都按此骨架展开。

| 段 | 名称 | 作用 | 注意 |
|----|------|------|------|
| 1 | **钩子 Hook** | 一个具体、不夸张的生活场景或反直觉提问，把读者拉进自己的处境 | 不制造恐慌，不写"再不X就晚了" |
| 2 | **反共识 Counter-consensus** | 点出一条被大众默认为真的假设，给出你的不同看法 | 必须可辩护，不是抬杠 |
| 3 | **支撑 Evidence** | 用模型/案例/数据/金句中至少两类素材支撑论点 | 见 `references/source-policy.md` |
| 4 | **破局 Reframe** | 把"问题"重新定义为"选择"，给可迁移的思维视角 | 给希望，不给鸡汤 |
| 5 | **行动 Action** | 1-3 个小步、低成本、今天就能开始的建议 | 拒绝完美主义启动 |
| 6 | **收束 Close** | 一句金句或回到长期主义的余味 | 不催促、不恐吓 |

## 工作流程

### 第1步：确认上下文

**先读取 `assets/user-profile.md`（如果存在）**，作为默认值：

- **主题方向**：用户给的 > profile 中的 default_topic > 反共识/长期主义/反焦虑
- **受众**：用户说的 > profile 中的 audience > 30-50 岁
- **产出类型**：用户指定的（大纲/全文/标题/素材卡）> profile 中的 output_format > full
- **风格强度**：用户说的 > profile 中的 tone > 平和、笃定、不油腻
- **平台**：用户说的 > profile 中的 platform > 公众号

对话中提供的信息**覆盖** profile 默认值。

### 第2步：选题与安全筛查

用户给的选题/方向，先过 `references/style-boundary.md` 的红线和禁用清单：

- 是否制造年龄/身份/阶层恐慌？→ 改写，去掉恐慌钩子
- 是否承诺速效/治愈/逆袭？→ 改为"可能有助于 / 值得一试"
- 是否依赖编造数据？→ 改用可查证数据或明确标注"示意"
- 是否标题党？→ 重写，保留真实价值钩子

### 第3步：选择素材

按 `references/source-policy.md` 的四类素材策略，为选题匹配：

- **金句**：可引用的观点句（自创或注明出处的他人）
- **模型**：可复用的思维模型/框架（如"控制二分法""复利思维"）
- **案例**：真实或 anonymized 的具体故事
- **数据**：可查证的研究/统计数字

每篇至少两类；full 产出建议四类都触达。

### 第4步：生成内容

按 `assets/article-template.md` 的六段骨架生成。产出形态由 output_format 决定：

| 形态 | 内容 | 体量 |
|------|------|------|
| `outline` | 选题 + 六段大纲 + 每段素材建议 | ~400字 |
| `full` | 完整公众号长文（六段展开） | ~1500-2500字 |
| `titles` | 8-12 个标题/开头钩子，含 AB 测试分组 | ~300字 |
| `cards` | 金句/模型/案例/数据 四类素材卡 | 4-8张 |

### 第5步：个性化调整

| 用户情况 | 调整重点 |
|----------|----------|
| 职场困境 | 锚定"可控 vs 不可控"，给低成本的注意力重分配 |
| 育儿/家庭 | 去比较、去完美主义，强调长期陪伴节奏 |
| 自我成长焦虑 | 用"复利"替代"速成"，拆解小步行动 |
| 中年转型 | 强调"重新开始不晚"的确定性证据，不画大饼 |

## Gotchas（真实翻车案例，持续积累）

> 每次发现模型犯错，记录在这里。

| # | 翻车场景 | 根因 | 防御措施 |
|---|----------|------|----------|
| G1 | 标题写成"30岁不努力，40岁就被淘汰" | 滑入年龄恐慌式标题党 | 标题只给真实价值钩子，禁用"淘汰/晚了/来不及" |
| G2 | 通篇"你一定要""必须马上做" | 爽文叙事惯性 | 用"可以试试/值得考虑"，不命令 |
| G3 | 引用"某研究显示90%人失败"但无出处 | 编造数据撑论点 | 数据必须可查证，否则标注"示意/举例" |
| G4 | 反共识变成纯抬杠无依据 | 为反而反 | 反共识段必须配支撑素材，否则重写 |
| G5 | 结尾"现在就行动否则落后" | 恐吓式收束 | 收束回长期主义，给确定性不给催促 |
